**Antes de construir aplicações, é preciso aprender a construir soluções.**

Este repositório reúne meus estudos e exercícios de Lógica de Programação, desenvolvidos com base nos métodos de Manzano e Faccat.
Aqui estou fortalecendo a principal habilidade de um desenvolvedor: o raciocínio lógico.

Mais do que aprender sintaxe, este projeto representa minha evolução na criação de algoritmos, resolução de problemas e entendimento do fluxo de execução de programas.

---

 # O que estou desenvolvendo aqui?
 
 -Estruturas condicionais (se, senão)
 
 -Operadores lógicos e matemáticos
 
 -Estruturas de repetição
 
 -Variáveis e manipulação de dados
 
 -Construção de algoritmos
 
 -Resolução de problemas passo a passo
 
 -Pensamento computacional

 ---

 # Objetivo do Projeto
 
 Criar uma base sólida antes de avançar para tecnologias mais complexas como:

 -JavaScript
 
 -React
 
 -Banco de Dados

 -Backend
 
 -Python

- Inteligência Artificial
  
Acredito que dominar lógica primeiro torna qualquer linguagem mais fácil de aprender depois.


Se você é um recrutador ou colega desenvolvedor e deseja discutir sobre **algoritmos** e **lógica de programação**, sinta-se à vontade para explorar os arquivos deste repositório!  
Aqui estão reunidas as soluções dos exercícios da **Apostila FACQAT**, que foram fundamentais para desenvolver meu raciocínio lógico e aprimorar minhas habilidades em programação.
